# Peacock Zaika – Restaurant Website 🍽️

Peacock Zaika is a **responsive restaurant website** created using **HTML5 and CSS3**.  
This project is built as a **frontend practice project** to strengthen layout design, responsiveness, and UI styling skills.

---

## 🚀 Project Overview

The website represents an **authentic Indian restaurant** offering traditional cuisine.  
It includes essential sections commonly found in real-world restaurant websites such as:

- Navigation bar
- Hero section
- Menu listing
- About section
- Contact & reservation form
- Footer with opening hours and social links

This project focuses purely on **frontend design**, without JavaScript or backend integration.

---

## 🛠️ Technologies Used

- **HTML5** – For page structure and semantic layout  
- **CSS3** – For styling, layout, responsiveness, and animations  
- **Google Fonts (Poppins)** – For modern typography
